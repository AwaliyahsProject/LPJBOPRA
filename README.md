# LPJ BOP RA

Aplikasi pencatatan BOP Raudhatul Athfal: Buku Kas Umum, buku pembantu bank/tunai/pajak, LPJ bendahara, rekap tahap, kuitansi, dan unduh Excel LPJ sesuai template.

Buka `index.html` melalui GitHub Pages, lalu pasang ke layar depan HP (Android: menu ⋮ > Instal aplikasi; iPhone: Bagikan > Tambah ke Layar Utama).

Data tersimpan di perangkat masing-masing (tidak diunggah). Gunakan menu **Unduh Excel > Unduh cadangan / Pulihkan dari file** untuk memindahkan data.
